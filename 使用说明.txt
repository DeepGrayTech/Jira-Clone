========================================================
                    About this project
========================================================

This is a task management kanban app with multi-user support.

Features:
- Kanban view: To Do, In Progress, Done
- Create tasks: Click "New Task" button
- Edit tasks: Click on a task card
- Delete tasks: Click "Delete" on a task card
- Priority: Low, Medium, High, Urgent (color-coded)
- Due date support
- Tags support (comma separated)
- Requirements, test cases, bug tracker, goals, epics
- Multi-user login (NextAuth), data isolated per account

Note: Data is stored in a server-side SQLite database
(prisma/dev.db), NOT in the browser. It survives refresh
and is tied to your login account.


========================================================
                    Login accounts
========================================================

Two accounts are created automatically on first run:

  demo@example.com  / demo123   (USER, with sample data)
  admin@example.com / admin123  (ADMIN)

The login form is pre-filled with the demo account,
so you can just click "Log in".


========================================================
                    Steps to start
========================================================

Step 1: Check Node.js
- Press Win+R, type "cmd", press Enter
- Type "node --version" and press Enter
- If you see a version number, Node.js is installed
- If not, download LTS version from https://nodejs.org/

Step 2: Start the project
- Double-click "启动项目.bat"
- First run takes a few minutes. The script will:
  1. Install dependencies (npm install)
  2. Create the .env config file if missing
  3. Generate the Prisma client
  4. Initialize the SQLite database and seed accounts
  5. Start the dev server

Step 3: Use
- Open http://localhost:3000 in your browser
- Log in with demo@example.com / demo123 (pre-filled)
- Start using!


========================================================
                    Common issues
========================================================

Issue 1: Double-clicking the bat file does nothing
Solution: Right-click the bat file, choose "Edit" to see if content is correct

Issue 2: "node is not recognized" error
Solution: Install Node.js from https://nodejs.org/

Issue 3: npm install is slow
Solution:
1. Press Win+R, type "cmd", press Enter
2. Type this command and press Enter:
   npm config set registry https://registry.npmmirror.com
3. Then double-click "启动项目.bat" again

Issue 4: Port already in use
Solution: Not needed anymore - "npm run dev" auto-frees
ports 3000-3002 on startup. If it still fails, restart
your computer.

Issue 5: Login fails with "Invalid email or password"
Solution: The database may be missing the seed accounts.
Run these commands in the project folder:
   npm run db:seed
Then try demo@example.com / demo123 again.

Issue 6: Page shows a Prisma/database error
Solution: The database may be out of sync. Reset it:
   npm run db:reset
   npm run db:seed
WARNING: this deletes all data and restores demo data.
